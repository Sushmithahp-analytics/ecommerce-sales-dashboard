# E-commerce Sales Dashboard

## 📊 Project Overview
This project is a Power BI dashboard analyzing e-commerce sales performance across products, regions, and time.

## 🔧 Tools Used
- Power BI
- Excel

## 📈 Key Insights
- Analyzed sales trends over time
- Identified top-performing products and categories
- Compared regional sales performance
